AI chatbots were used. The uses includes problems solving relating to build and compilation errors relating to vcpkg. The chatbot was used to identify the problem, in this case being the location of the vcpkg download and providing console commands to direct the minigame to the download location.



Other uses were for debugging purposes. When errors during the code writing process was met and no one in the group knew a solution, the error would be posted into a chatbot with relevant context to try and understand why the error was happening. Often times the result lead to a fix when the error was understood and other times it atleast jumpstarted our brains to what the error was related to.



Finally the same chatbots were used for easy access into C++ and OpenCV documentation. When we did not know the possible c++ or opencv commands we would ask an AI chatbot to provide examples with relevant sources. The examples for code documentation was not pasted in unless it was understood first and majority of time it was adapted into the code instead of pasted.
